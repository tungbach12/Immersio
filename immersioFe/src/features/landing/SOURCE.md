# Design reference

Reference: https://21stdev-my-components-one.vercel.app/#torn-postcard-portfolio

Original Torn Postcard Portfolio component by @kedhareswer, published in the
21ST.DEV workshop: https://21st.dev/@kedhareswer

The public browser-delivered component was adapted into a standalone React
project. The torn paper, pointer parallax, postcard flip, polaroid carousel,
and animated journey interactions come from this reference.

The English learning content, evergreen colour palette, book/flashcard/learner/
headphone/paper plane illustrations, brand mark, and interactive lesson preview
were created for this Immersio landing page. The reference's landscape assets
and portfolio/contact content have been replaced.
